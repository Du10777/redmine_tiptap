# Переводы редактора

Тексты редактора (подсказки тулбара, меню, диалоги, список языков кода, тексты вставляемых блоков) лежат не в JavaScript, а в файлах этой папки: по файлу на язык.

Редактор показывает их на языке, выбранном в профиле Redmine (Моя учётная запись → Язык). Тот, кто не вошёл в систему, получает язык, который Redmine подберёт для него: язык браузера, если он есть в Redmine, иначе язык Redmine по умолчанию. Текст, которого нет в файле, показывается по-английски (язык с регионом сначала смотрит в язык без региона, см. [«Языки с регионом»](#языки-с-регионом)).

Для 47 из 50 языков Redmine здесь есть файл. Остальные три пишутся справа налево и сознательно не поддерживаются, см. [«Языки справа налево»](#языки-справа-налево).

| Файл | Язык |
|---|---|
| `en.yml` | Английский. Источник всех переводов: здесь есть каждый текст. |
| `ru.yml` | Русский, авторский. |
| остальные 45 файлов | Остальные языки Redmine, см. [таблицу](#языки-redmine) ниже. |

**Эти 45 переводов — черновики.** Они сделаны с помощью ИИ-модели и не проверены носителями языков. Они придерживаются формулировок собственного интерфейса Redmine на каждом языке, но местами возможны неловкие фразы. Исправления приветствуются.

## Как улучшить перевод

1. Откройте `<код>.yml` нужного языка и измените значения. Ключи (слова перед двоеточием) оставьте как есть, тексты оставьте в двойных кавычках. Первые символы пунктов списков (`☑`, `•`, `1.`, `a.`) — часть текста, их можно оставить. Тексты простые, HTML в них показывается как есть.
2. Проверьте файл, в папке Redmine:
   ```sh
   bundle exec rake redmine_tiptap:locales RAILS_ENV=production
   ```
3. Перезапустите Redmine, чтобы увидеть изменение.
4. Пришлите файл pull request'ом или заведите issue с тем, что нужно поменять. Когда носитель языка пройдёт файл целиком, пометка «черновик» убирается из шапки файла и из таблицы ниже.

Проверка сообщает и о ключах, которых нет в `en.yml` (опечатка или удалённый текст), о файле, у которого первая строка не совпадает с именем, о коде, которого нет среди языков Redmine, и о неверном YAML. Если что-то найдено, она завершается с ошибкой, так что её можно запускать из скрипта. Чтобы увидеть, чего ещё не хватает языку, добавьте `LOCALE=de`:

```sh
bundle exec rake redmine_tiptap:locales LOCALE=de RAILS_ENV=production
```

Когда в плагине появляется новый текст, его добавляют в `en.yml` и `ru.yml`. Пока его нет в файле языка, он показывается по-английски; проверка выводит такие тексты списком.

## Как добавить язык

Все языки Redmine 6.1.4 уже имеют файл, кроме трёх, которые пишутся справа налево (см. [«Языки справа налево»](#языки-справа-налево)). Этот раздел — для языка, который принесёт более поздний Redmine, и для форка, который добавляет один из этих трёх.

1. Найдите его код в [списке языков Redmine](#языки-redmine) (работают только такие коды: файл с любым другим кодом никогда не будет использован).
2. Скопируйте `en.yml` в `<код>.yml`, например `de.yml`.
3. Замените первую строку `en:` на `<код>:` (`de:`). Для норвежского пишите `"no":` в кавычках: YAML читает голое `no:` как слово «ложь».
4. Переведите значения, как описано выше. Переводить всё сразу не обязательно: текст, которого нет или который оставлен пустым, показывается по-английски.

## Языки с регионом

Язык с регионом сначала берёт язык без региона, а затем английский, отдельно для каждого текста:

| Код | Берёт |
|---|---|
| `pt-BR` | `pt` |
| `zh-TW` | `zh` |
| `en-GB` | `en` |
| `es-PA` | `es` |
| `sr-YU` | `sr` |

`pt-BR.yml` (бразильский португальский), `zh-TW.yml` (традиционный китайский) и `sr-YU.yml` (сербский латиницей) — самостоятельные полные переводы. В `en-GB.yml` и `es-PA.yml` лежат только немногие тексты, которые отличаются от `en.yml` (британское написание: colour, centre) и `es.yml`; остальные тексты приходят из языка без региона, поэтому правку общего текста нужно вносить в `en.yml` или `es.yml`. У `ta-IN` (тамильский) запасного языка нет: простого `ta` в Redmine нет.

## Названия языков подсветки

Названия и подсказки языков кода (Python, SQL, ...) приходят из файлов языков в папке `highlight/`, по-английски. Файл перевода может изменить, как язык выглядит в списке и на ярлыке блока кода, и добавить слова, по которым язык находится в поиске; для этого нужен раздел `code_languages:` и `id` языка:

```yaml
de:
  redmine_tiptap:
    code_languages:
      routeros:
        label: "..."      # показывается вместо названия из highlight/routeros.js
        hint: "..."       # показывается вместо серой подсказки
        keywords: "..."   # дополнительные слова для поиска, к английским
```

Все три поля необязательные. Поиск по английским словам работает всегда. Настоящие примеры — в `ru.yml`; черновики переводов оставляют названия по-английски. `id` должен совпадать с именем файла в `highlight/` (неверный проверка покажет).

## Языки справа налево

Арабский (`ar`), иврит (`he`) и персидский (`fa`) пишутся справа налево. **Плагин их не поддерживает, и это сознательное решение.** Поддержка языка с письмом справа налево — это не только файл перевода, а много изменений в кодовой базе, и мы решили не брать на себя эту работу и её сопровождение. Для пользователя, у которого в Redmine выбран один из этих трёх языков, файла здесь нет, поэтому редактор показывается по-английски. Redmine зеркалит страницу, но вёрстка редактора не подгонялась и не проверялась, и части её могут выглядеть неверно.

Если вам нужен один из этих языков, сделайте форк. Со стороны перевода всё готово: скопируйте `en.yml` в `ar.yml`, `he.yml` или `fa.yml` и переведите, как описано в разделе [«Как добавить язык»](#как-добавить-язык). Остальное — вёрстка. Когда это пробовали, работа нашлась в таких местах:

- В стилях редактора левая и правая сторона названы примерно в дюжине мест: рамка цитаты, отступ списков, угол с ярлыком языка и кнопкой «Копировать», стрелка поля размера шрифта, ручка изменения высоты, выравнивание заголовков таблицы. Их нужно заменить на начало и конец строки (логические свойства CSS, например `padding-inline-start` и `inset-inline-end`).
- На странице с письмом справа налево Redmine 6 добавляет каждому абзацу формы отступ справа шириной в колонку подписей. Плагин сбрасывает только левый отступ, поэтому текст редактора отодвигается на 180px от края, а каждая таблица становится в пять раз шире.
- Выпадающие меню, палитра цвета и список языков ставятся по левому краю своей кнопки. На странице справа налево их надо ставить по правому краю, иначе они уезжают за страницу.
- Код лучше рисовать слева направо при любом направлении страницы. Иначе алгоритм двунаправленного текста браузера переставляет части строки кода (одинокая `}` выглядит как `{`), а ярлык языка закрывает первые символы строки.
- Кнопки отступа записывают в сохранённый текст `margin-left`, поэтому выровненный вправо текст не сдвигается. Для исправления нужно менять формат сохранённого текста и список разрешённых стилей в `lib/redmine/wiki_formatting/tiptap/sanitizer.rb`.
- Библиотека таблиц тянет границу столбца наоборот на странице справа налево.
