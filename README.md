This is text editor for Redmine, based on TipTap https://github.com/ueberdosis/tiptap

Supported Redmine versions: **6.\*** (developed and tested on 6.1.4).

Installation:
1. Place "redmine_tiptap" folder in redmine "plugins" folder
2. In redmine settings (redmine.selfhosted/_settings_) choose Text formatting: *TipTap HTML*
