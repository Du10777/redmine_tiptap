# redmine_tiptap

A WYSIWYG editor for Redmine, based on TipTap. Try it online: https://du10777.github.io/redmine_tiptap/?lang=en

This is the `release` branch: only the files the plugin needs to run. The documentation (in 42 languages), the supported
versions of Redmine and the history of the changes are in the `main` branch: https://github.com/Du10777/redmine_tiptap

Install, in the folder of Redmine:

    git clone --branch release --single-branch --depth 1 https://github.com/Du10777/redmine_tiptap.git plugins/redmine_tiptap

Update, in `plugins/redmine_tiptap`: `git pull`, then restart Redmine.
