# The demo of redmine_tiptap

This branch is the site https://du10777.github.io/redmine_tiptap/ (GitHub Pages): the editor of the plugin on a
page made like a form of Redmine, with a preview of the saved text and a choice of the interface language.

The files are put together from the `main` branch: the editor (`plugin/`) and its translations (`i18n/`) are
the files of the plugin; `index.html`, `demo.js`, `preview.js`, `demo.css` and `samples.js` are the page itself;
`redmine/` holds the styles, icons and fonts of Redmine 6.1.5 (GNU GPL v2, (c) Jean-Philippe Lang; Noto Sans
under the SIL Open Font License, see `redmine/fonts/OFL.txt`).
