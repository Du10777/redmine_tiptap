Блокови кода истичу се подједнако у уређивачу и на сачуваним страницама (проблеми, белешке, вики), и izgledaju исто на оба места. Језик блока бира се помоћу значке у његовом горњем десном углу. Листа језика одређена је датотекама у фасцикли `highlight/`: једна датотека је један језик.

Додатна компонента долази са 52 језика. Можете додати више: конвертујте готову highlight.js граматику помоћу скрипта (видити [Додавање језика из highlight.js](#додавање-језика-из-highlightjs)) или напишите своју.

## Како функционише

- Истицање синтаксе врши [highlight.js](https://highlightjs.org) (кроз [lowlight](https://github.com/wooorm/lowlight)). Уређивач и сачуване странице користе исти механизам, тако да се боје поклапају.
- `_compile.sh` пакује све датотеке језика у једну датотеку, `assets/javascripts/tiptap_highlight.js`. Ова датотека је већ изграђена у репозиторијуму, тако да инсталација додатне компоненте не захтева изградњу. Требате да је изградите само када промените скуп језика.
- Redmine учитава `tiptap_highlight.js` на свакој страници, пре уређивача (`tiptap_bundle.js`). При учитавању уређивач региструје све језике из те датотеке.
- У уређивачу блок се поново истиче 50 ms после што паузирате куцање, и само блок који се променио. На сачуваним страницама блок се истиче када се помера у видно поље. Блок унутар склопљене секције истиче се када се секција отвори.
- Језик се чува у сачуваном HTML-у: `<pre><code class="language-<id>">`. Због тога `id` језика никада не сме да се промени: блокови сачувани са старим `id` би постали обичан текст.
- Нема аутоматске детекције језика: блок без језика приказује се као обичан текст. Исто се дешава са блоком чији језик није у `highlight/` (на пример, датотека језика је избрисана); његова значка наставља да показује `id`. Ако се датотека језика врати, врате се и боје.
- Боје. highlight.js обележава текст класама као што су `hljs-keyword`, `hljs-string`, `hljs-comment`. Њихове боје постављене су у `assets/stylesheets/src/06_code.css`, користећи палету Redmine-овог сопственог истицања синтаксе.

## Датотека језика

На пример, `routeros.js`:

```js
import grammar from 'highlight.js/lib/languages/routeros';

export default {
  id: 'routeros',
  label: 'RouterOS',
  hint: 'MikroTik',
  keywords: 'mikrotik',
  grammar: grammar,
};
```

| Поље | Обавезно | Шта је то |
|---|---|---|
| `id` | да | Назив језика у сачуваном HTML-у (`class="language-<id>"`). Дозвољени карактери: `a-z`, `0-9`, `-`, `_`. **Никада га не мењајте** када су блокови са овим језиком већ сачувани. |
| `label` | не | Назив у листи језика и на значки блока. Подразумевано је `id`. |
| `hint` | не | Сива напомена поред назива у листи. |
| `keywords` | не | Додатне реч за претрагу у листи, одвојене размаком. |
| `grammar` | да | Граматика highlight.js: функција `(hljs) => language definition`. |

`label`, `hint` и `keywords` су на енглеском. Да би се језик приказао под другим називом на језику интерфејса корисника, или да би се могао наћи рачима тог језика, додајте унос у датотеку превода тог језика, `config/locales/<code>.yml`, под `code_languages:`. Реч тамо додају се `keywords`; `label` и `hint` замењују оне из датотеке језика. `config/locales/ru.yml` има примере, правила су у [config/locales/README.md](../../config/locales/README.md).

Врсте датотека у фасцикли:

- **Кратка.** Референца на граматику из highlight.js npm пакета, као у примеру изнад; већина језика је таква. Граматика долази из highlight.js верзије забележене у `package-lock.json` додатне компоненте.
- **Пуна копија.** Код граматике је у самој датотеци и може се уредити. Ове датотеке прави скрипта за конверзију (видити доле).
- **Властита граматика.** `log.js`, `journalctl.js`, `cisco-ios.js`; њихови заједнички делови су у `_common.js`.
- **Обвијач.** Готова граматика под другим називом: `cmd.js` је `dos` из highlight.js, `docker-compose.js` је `yaml`.

Датотеке и фасцикле чија имена почињу са `_` нису језици:

- `_compile.sh` изграђује језике;
- `_check.mjs` проверава језике при изградњи;
- `_common.js` садржи заједничке делове властитих граматика додатне компоненте;
- `_convert_grammar.py` је скрипта која конвертује highlight.js граматике (видити доле);
- `_vendor/` садржи датотеке которе конвертована граматика увози (прави скрипта за конверзију).

Фасцикла `README/` садржи ову документацију.

## Додавање језика из highlight.js

Готове граматике (више од 190) су овде: https://github.com/highlightjs/highlight.js/tree/main/src/languages. Њихови називи и алијаси наведени су у [SUPPORTED_LANGUAGES.md](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md), заједно са око стотину граматика треће стране чувани у одвојеним репозиторијумима. Скрипта `_convert_grammar.py` у овој фасцикли конвертује било коју од њих у формат додатне компоненте.

Скрипта захтева Python 3.6+ (без додатних пакета) и приступ github.com. Покрените је из фасцикле додатне компоненте:

```sh
cd /path/to/redmine/plugins/redmine_tiptap
python3 highlight/_convert_grammar.py erlang
sh highlight/_compile.sh
```

Аргумент `erlang` је назив датотеке у `src/languages` без `.js`. Друга команда изграђује језике и проверава их. Затим поново покрените Redmine (видити [Изградња и примена](#изградња-и-примена)). На Windows користите `py` или `python` уместо `python3`.

Примери:

```sh
# листа highlight.js језика (* = већ у highlight/), опционално филтрирана по речи
python3 highlight/_convert_grammar.py --list
python3 highlight/_convert_grammar.py --list sql

# неколико језика одједном
python3 highlight/_convert_grammar.py erlang nix fsharp

# властити назив, напомена и речи за претрагу (један језик одједном)
python3 highlight/_convert_grammar.py erlang --label "Erlang/OTP" --hint BEAM --keywords "erl otp"

# замени кратку датотеку достављену са додатном компонентом уредивом пуном копијом
python3 highlight/_convert_grammar.py routeros --force --label RouterOS --hint MikroTik --keywords mikrotik

# језик није још у пуштеној highlight.js верзији, из развојне гране
python3 highlight/_convert_grammar.py odin --ref main

# веза на датотеку граматике, директно из адресне линије прегледача
python3 highlight/_convert_grammar.py https://github.com/highlightjs/highlight.js/blob/main/src/languages/odin.js

# граматика треће стране: веза на њен репозиторијум, скрипта проналази датотеку граматике
python3 highlight/_convert_grammar.py https://github.com/highlightjs/highlightjs-terraform

# локална датотека граматике
python3 highlight/_convert_grammar.py ~/grammars/mylang.js --id mylang

# кратка датотека која референцира npm пакет уместо копије кода
python3 highlight/_convert_grammar.py erlang --npm

# покажи шта би урадио без измене чега год
python3 highlight/_convert_grammar.py erlang --dry-run
```

### Шта скрипта ради

1. Преузима `src/languages/<name>.js` highlight.js верзије на којој додатна компонента ради. Верзија се чита из `package-lock.json` (тренутно 11.12.0), јер су граматике написане за механизам своје верзије. `--ref` бира другу верзију, грану или комит.
2. Преузима назив језика из `Language:` линије заглавља граматике и речи за претрагу из њених алијаса (`aliases`). `id` је назив датотеке граматике.
3. Стави код граматике у `highlight/<id>.js` непромењено изузев извоза: `export default function(hljs)` постаје `function grammar(hljs)`, и објекат језика `export default { id, label, keywords, grammar }` прилаже се на крај датотеке. Ако је граматика CommonJS модул (`module.exports = ...`), линија која декларира `module` и `exports` додаје се на врх.
4. Ако граматика увози друге датотеке, преузима их у `highlight/_vendor/<source>-<version>/` под истим путањама као у репозиторијуму и упућује увозе тамо. На пример, `typescript` увози `javascript.js` и `lib/ecmascript.js`. Ове датотеке деле сви језици из истог извора и верзије; нема потребе да их уредите.
5. Проверава `Requires:` линију, која наводи језике коришћене за угнежђени код (на пример, `php-template` захтева `xml` и `php`). Ако их нема у `highlight/`, исписује команду која их додаје. Без њих угнежђени код останеђе необојен; ово није грешка.
6. Не препаковава постојеће датотеке без `--force` и не прихвата `id` већ коришћену од друге датотеке.

После конверзије језик може бити уредио право у својој датотеци.

### Опције

| Опција | Шта она ради |
|---|---|
| `LANGUAGE ...` | Назив highlight.js језика, веза на датотеку граматике или на репозиторијум граматике треће стране на GitHub-у, или путања до локалне `.js` датотеке. |
| `--ref REF` | highlight.js верзија (tag), гана или комит. Подразумевано је верзија у `package-lock.json`. За везе верзија се узима из саме везе. |
| `--id ID` | Језик `id`. Подразумевано је назив датотеке граматике. |
| `--label TEXT` | Назив у листи и на значки. Подразумевано је `Language:` из граматике. |
| `--hint TEXT` | Сива напомена у листи. |
| `--keywords TEXT` | Речи за претрагу одвојене размаком. Подразумевано су алијаси граматике. |
| `--npm` | Уместо копије кода, напишите кратку датотеку која референцира highlight.js npm пакет. Само за језике самог highlight.js. |
| `--force` | Замени постојеће датотеке. |
| `--dry-run` | Покажи шта би урадио без измене чега год. |
| `--list [WORD]` | Наведи highlight.js језике и граматике треће стране, опционално филтриране по речи. |
| `--prune` | Обриши датотеке у `_vendor/` које ниједан језик више не увози. |


**Копија или `--npm`?** Копија показује правила право у датотеци: можете је уредити, узети граматику новију од инсталираног пакета, или трећу страну. Копија се не мења када додатна компонента надогради highlight.js; да је освежите, поново конвертујте језик са `--force`. Датотека направљена са `--npm` је неколико редова дужа, а њена граматика надогради се заједно са додатном компонентом.

## Изградња и примена

```sh
sh highlight/_compile.sh
```

- Требиће Docker (изградња ради у `node:20-alpine` контејнеру) или, ако нема Docker-а, Node.js 18+ на истој машини. При првом извршавању скрипта инсталира npm пакете у фасциклу `node_modules/` додатне компоненте.
- Прво скрипта проверава сваки језик: изграђује га одвојено, учитава га, региструје га у истом механизму који ради у прегледачу, и истиче узорак текста. Ако је језик неисправан (грешка у коду, неважећи регуларни израз, `id` већ коришћен), скрипта назива датотеку и разлог и зауставља се; претходна `tiptap_highlight.js` остаје на месту.
- Затим скрипта пакује све језике у `assets/javascripts/tiptap_highlight.js`.

После изградње поново покрените Redmine: објављује датотеке додатних компоненти при покретању (видити „Ажурирање" у [главном README](../../docs/README.sr.md#ажурирање) за команде). Прегледачи преузимају нову датотеку одмах, јер њена адреса садржи отисак садржаја.

Ако Redmine сервер нема ни Docker ни Node.js, изградите на било којој машини која има неки од њих (копија фасцикле додатне компоненте је довољна) и ставите резултујућу `assets/javascripts/tiptap_highlight.js` на сервер.

## Уклањање језика

Избришите датотеку језика из `highlight/`, изградите, и поново покрените Redmine. Сачувани блокови на овом језику остају како су била и приказују се као обичан текст. Датотеке у `_vendor/` које више нису потребне уклањају се са:

```sh
python3 highlight/_convert_grammar.py --prune
```

## Властите граматике и правила уређивања

- Граматика је функција која добија објекат `hljs` и враћа дефиницију језика: која места текста обележи и како. Водич: https://highlightjs.readthedocs.io/en/latest/language-guide.html, референца: https://highlightjs.readthedocs.io/en/latest/mode-reference.html. Примери: `log.js`, `journalctl.js`, `cisco-ios.js`.
- highlight.js спаја регуларне изразе свих правила језика у један и игнорише њихове сопствене заставице. Тако да подударање без разликовања великих и малих слова мора бити израђено (`[Ee]rror`) или омогућено за цели језик са `case_insensitive: true`.
- Предпочините стандардне класе жетона (`keyword`, `string`, `number`, `comment`, `title`, `attr`, `variable`, `built_in`, `literal`, `meta`, `symbol`, `type` и сл.): већ имају боје. Класа од вас (на пример, `scope: 'log-error'` производи класу `hljs-log-error`) захтева правило у `assets/stylesheets/src/06_code.css` и обнову CSS-а (`assets/stylesheets/src/_build.sh`).
- Да понудите готову граматику под другим називом, учините као што `cmd.js` ради: позовите оригиналну граматику и промените `name` и `aliases` у њеном резултату. Ако алијаси нису замењени, нови језик их преузима од оригиналног.

## Ажурирање додатне компоненте када сте додали језике

git оставља ваше датотеке у `highlight/` саме. Али `assets/javascripts/tiptap_highlight.js` у новој верзији додатне компоненте изграђена је без ваших језика, а ваша изградња ове датотеке замршава `git pull`. Тако:

```sh
cd /path/to/redmine/plugins/redmine_tiptap
git checkout -- assets/javascripts/tiptap_highlight.js
git pull
sh highlight/_compile.sh
```

Прва команда одбацује вашу изградњу, последња одбацује језике поново, укључујући ваше. Затим поново покрените Redmine. Ако сте уредили датотеке језика достављене са додатном компонентом, git може да вас моли да разрешите конфликте у њима.

Ако је додатна компонента инсталирана из архиве, сачувајте ваше датотеке језика и фасциклу `_vendor/` пре замене фасцикле додатне компоненте, враћајте их назад после замене, и изградите језике.

## Величина

Сви језици су пакони у једну датотеку; прегледач је преузима једном и затим је узима из кеша. Тренутно је 226 KB за 52 језика. Већина језика заузима 1–10 KB, највећи је 1C (55 KB).
