これは Redmine 用のテキストエディターで、TipTap https://github.com/ueberdosis/tiptap をベースにしています。

サポートする Redmine のバージョン: **6.\***（6.1.4 で開発およびテストを行っています）。

エディターのエンジン: **TipTap 3.31.4**。`@tiptap/*` のパッケージはすべて、`package.json` と `package-lock.json` でこのバージョンに厳密に固定されています。アップグレードは、必ずすべてを一緒に、同一のバージョンへ行う必要があります。

## 機能

**テキスト書式**
- 太字、斜体、下線、取り消し線、インラインコード。
- 文字色と背景色: 64 色のパレット、または任意の 16 進カラーコード。
- フォントファミリー（13 種類のフォント）とフォントサイズ（8〜72 px のプリセット、または任意の値）。
- 段落スタイル: 見出し 1〜6 と標準テキスト。
- 段落と見出しの配置（左揃え、中央揃え、右揃え、両端揃え）とインデント（最大 8 レベル）。
- リンク: 挿入、編集、削除。
- 水平線、元に戻す、やり直し。

**リスト**
- 黒丸、白丸、四角のマーカーを使った箇条書きリスト。
- 番号付きリスト: 1、01、a、A、i、I、α。
- チェックボックス付きのタスクリスト。完了したタスクには取り消し線が付きます。
- 入れ子のリスト（Tab / Shift+Tab）。

**表**
- 任意のサイズの表を、ヘッダー行の有無を選んで挿入できます。
- セルの右クリックメニュー: 行と列の追加・削除、セルの結合・分割、ヘッダー行とヘッダー列、表の削除。
- 列の幅は、セルの境界線をドラッグして変更します。
- Excel から貼り付けると、列の幅、配置、フォントサイズが保持されます。Redmine からコピーした表は、罫線付きで Excel に貼り付けられます。

**画像と添付ファイル**
- クリップボードから画像を貼り付けると、添付ファイルとしてアップロードされ、テキストに表示されます。
- Redmine の「ファイル」フィールドで添付した画像や、そこにドロップした画像も、同様にテキストに挿入されます。
- 添付ファイルから画像を挿入（サムネイルから選択）したり、任意の添付ファイルへのリンクを挿入したりできます。
- 画像の隅をドラッグして、サイズを変更できます。

**コード**
- エディターと保存済みのページの両方でシンタックスハイライトが効くコードブロック。52 言語に対応しており、さらに追加できます（[シンタックスハイライト](#シンタックスハイライト)を参照）。
- ブロックの言語は、隅にあるバッジから選択します。検索のほか、最近使った言語やよく使う言語の表示にも対応しています。
- コードブロック内では、Tab で行をインデントし、Shift+Tab でインデントを解除できます。コード内の太字、リンク、色は保持されます。

**ブロック**
- 折りたたみブロック: タイトルと、その下に隠れる内容（`<details>`）。保存済みのページでは折りたたまれ、エディターでは展開された状態で表示されます。
- 著者と日付の行を付けられる引用ブロック。

**編集**
- HTML ソースを表示・編集するための `<HTML>` モード。
- Markdown 記法での入力: 見出しは `#`、リストは `-` と `1.`、タスクは `[ ]`、コードブロックは ```` ```python ````（言語名は何でも可、省略も可）、太字は `**bold**`、水平線は `---`。標準的なキーボードショートカット: Ctrl+B、Ctrl+I、Ctrl+U、Ctrl+Z など。
- エディターの高さがウィンドウの高さを超えることはありません。ツールバーとフォームのボタンは常に表示されたままで、テキストはエディター内でスクロールします。高さはウィンドウのサイズとページのズームに合わせて変わります。
- 右下隅のサイズ変更ハンドルで、高さを手動で設定できます。高さは記憶され、ダブルクリックすると自動の高さに戻ります。

**Redmine との連携**
- 書式を使用できるすべての Redmine のテキストフィールドで動作します。チケットの説明とコメント、Wiki ページ、ニュース、フォーラムのメッセージ、文書、プロジェクトの説明、長いテキストのカスタムフィールドのほか、後からページに表示されるフィールドにも対応しています。
- テキストは HTML として保存されます。エディターを使うには、Redmine の設定の「テキスト書式」で *TipTap HTML* を選択してください。
- インターフェース（ツールチップ、メニュー、ダイアログ）は、ユーザーの Redmine プロフィールで選択された言語に従います。Redmine の 50 言語のうち 47 言語がプラグインに同梱されています。英語とロシア語は完成しており、残りの 45 言語は AI モデルで作成した下書きで、ネイティブスピーカーによる修正を歓迎します。右から左へ書く 3 つの言語（アラビア語、ヘブライ語、ペルシア語）は、意図的にサポートしていません（[表示言語](#表示言語)を参照）。
- 大きなテキストでも高速に動作します。非表示のフォーム内のエディターは、フォームが開かれたときにだけ作成され、長いコードブロックは、表示領域にスクロールされたときにハイライトされます。
- 保存されたテキストは、安全でない HTML を除いて表示されます。ページの表示時に、スクリプト、イベントハンドラー、`javascript:` リンクが削除され、エディター自身が生成するものだけが残ります。これは、REST API や `<HTML>` モード経由で入力されたテキストにも当てはまります。

## シンタックスハイライト

コードブロックは、エディターでも保存済みのページでも同じようにハイライトされます。ブロックの言語は、右上隅のバッジから選択します。一覧には検索ボックスがあり、最近使った言語とよく使う言語が記憶されます。

プラグインには 52 言語が同梱されており、その中には 1C、Cisco IOS、MikroTik RouterOS、Windows cmd、docker compose、Linux のサービスログ、journalctl の出力が含まれます。

独自の言語を追加することもできます。各言語は `highlight/` フォルダー内の 1 つのファイルです。190 以上ある highlight.js の文法のどれでも、またはサードパーティ製の文法でも、1 つのコマンドでそのようなファイルに変換できます。

```sh
python3 highlight/_convert_grammar.py erlang
sh highlight/_compile.sh
```

詳細は [highlight/README/ja.md](../highlight/README/ja.md) を参照してください。

## 表示言語

エディターは、ユーザーが Redmine のプロフィール（個人設定 → 言語）で選択した言語で表示されます。Redmine 6 の 50 言語のうち 47 言語のファイルがプラグインに同梱されており、`config/locales/` にあります。英語が原文で、ロシア語は作者自身によるものです。残りの 45 言語は AI モデルの助けを借りて作成した下書きで、ネイティブスピーカーによる確認はまだ行われていないため、ところどころ不自然な表現が含まれている可能性があります。ファイルにないテキストは英語で表示されます。

翻訳を修正するには、`config/locales/<code>.yml`（`de`、`fr`、`pt-BR` など）の値を変更して、Redmine を再起動します。`bundle exec rake redmine_tiptap:locales` でファイルを検証できます。修正を含むプルリクエストを歓迎します。

**右から左へ書く言語（アラビア語、ヘブライ語、ペルシア語）は、意図的にサポートしていません。** これらの言語に対応するには、翻訳だけでなく、コードベースに多くの変更を加える必要があり、私たちはそれを引き受けないことにしました。これらの言語では、エディターは英語で表示され、レイアウトの調整も行われません。いずれかの言語が必要な場合は、フォークを作成してください。翻訳の仕組みは用意されており、そのほかに変更が必要な箇所は [config/locales/README.md](../config/locales/README.md#right-to-left-languages) に一覧があります。

詳細と Redmine の言語の一覧は、[config/locales/README.md](../config/locales/README.md) を参照してください。

## インストール

1. プラグインを Redmine の `plugins` フォルダーに配置します。フォルダー名は `redmine_tiptap` にする必要があります。最も簡単な方法は git を使うことで、アップデートもコマンド 1 つで済みます。
   ```sh
   cd /path/to/redmine
   git clone https://github.com/Du10777/redmine_tiptap.git plugins/redmine_tiptap
   ```
2. Redmine を再起動します。
3. Redmine の設定（redmine.selfhosted/_settings_）の「テキスト書式」で *TipTap HTML* を選択します。

## アップデート

このプラグインにはデータベースのマイグレーションがなく、ビルド済みの JavaScript バンドルとスタイルシートはリポジトリに含まれています。アップデートには、サーバー上での npm もビルドも必要ありません。プラグインのファイルを置き換えて、Redmine を再起動してください。

アップデートの前に、新しいバージョンがお使いの Redmine のバージョンをサポートしていることを確認してください（上の「サポートする Redmine のバージョン」を参照）。

### git でインストールした場合（推奨）

```sh
cd /path/to/redmine/plugins/redmine_tiptap
git pull
```

続いて、たとえば次のように Redmine を再起動します。

```sh
sudo systemctl restart redmine          # systemd サービスとして動作している Redmine
touch /path/to/redmine/tmp/restart.txt  # Passenger
docker compose restart redmine          # Docker
```

最新のコミットではなく特定のバージョンにとどまるには、`git fetch && git checkout <tag-or-commit>` を実行します。

### アーカイブからインストールした場合

1. 古い `plugins/redmine_tiptap` フォルダーを削除し、その場所に新しいバージョンを展開します。先に削除しておくことで、新しいバージョンで削除されたファイルが残らないようにします。
2. Redmine のフォルダー内の `public/assets/.manifest.json` を削除します。
3. Redmine を再起動します。

手順 2 は重要です。Redmine は起動時に、プラグインのアセットのファイルがこのマニフェストより新しい場合にのみ、アセットを公開し直します。アーカイブから展開したファイルは元のタイムスタンプを保持するため、手順 2 を行わないと、Redmine が古いエディターを配信し続けることがあります。マニフェストは起動時に自動的に再作成されます。`git pull` を使う場合、この手順は不要です。git は、変更されたファイルに現在の時刻を設定するためです。

### アップデート後

- エディターのスクリプトとスタイルシートは、URL にコンテンツのフィンガープリントが付いた形で配信されるため、ブラウザーは再起動の直後に新しいバージョンを読み込みます。ユーザーがブラウザーのキャッシュを消去する必要はありません。
- Redmine の設定（管理 → 設定 → 全般）で *テキスト書式の変換結果をキャッシュ* が有効になっている場合は、HTML のサニタイズを備えたバージョンへアップデートした後に、一度だけ Redmine のキャッシュをクリアしてください。Redmine のフォルダーで `bundle exec rake tmp:cache:clear RAILS_ENV=production` を実行します。そうしないと、アップデート前に生成されたページが、テキストが変更されるまで、サニタイズされないままキャッシュから表示されることがあります。
- 以前のバージョンのプラグインは、スクリプトを `public/tiptap_bundle.js` にコピーしていました。これらのファイルはもう使われておらず、削除できます。
  ```sh
  rm -f /path/to/redmine/public/tiptap_bundle.js /path/to/redmine/public/tiptap_bundle.js.map
  ```
